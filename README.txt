# LenART — pierwsza wersja

Prywatna aplikacja do organizowania wydarzeń w estetyce Ivory.

## Uruchomienie na komputerze
1. Rozpakuj ZIP.
2. Otwórz `index.html` w przeglądarce, aby przetestować podstawowe funkcje.
3. Do instalacji PWA i działania offline potrzebny jest hosting HTTPS (np. GitHub Pages).

## Instalacja na iPhonie
1. Opublikuj folder na hostingu HTTPS.
2. Otwórz adres strony w Safari na iPhonie.
3. Wybierz Udostępnij → Dodaj do ekranu początkowego.
4. Uruchamiaj LenART z ikony na ekranie.

## Co zawiera wersja 0.1
- Dashboard i wydarzenia
- Zadania z terminami i priorytetami
- Lista gości
- Budżet i wydatki
- Usługodawcy
- Harmonogram
- Inspiracje i notatki
- Archiwum wydarzeń
- Kopia zapasowa JSON i import danych

## Ważne ograniczenia prototypu
- Dane są zapisywane lokalnie w przeglądarce na urządzeniu.
- Usunięcie danych witryny lub zmiana przeglądarki może je skasować; regularnie eksportuj kopię zapasową.
- Powiadomienia push, załączanie zdjęć z uploadem, synchronizacja i automatyczne przypomnienia nie są jeszcze wdrożone.
- Interfejs używa Google Fonts, gdy jest dostępny internet; bez internetu użyje fontów systemowych.
